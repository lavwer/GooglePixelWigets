# Widget Craft — виджеты с шаблонами, фото и часами

Профессиональное Android-приложение с домашними виджетами: стильные аналоговые часы,
фоторамка с вашими фото и комбинированный виджет «фото + часы». 8 встроенных шаблонов
оформления: Неон, Золото, Минимализм, Ретро, Океан, Закат, Лес, Графит.

## Возможности

- **Часы** — аналоговый циферблат рисуется программно: градиентный циферблат,
  светящиеся стрелки, метки, плавный ход секундной стрелки (обновление каждую минуту,
  стрелки — по реальному времени).
- **Фоторамка** — ваше фото из галереи, центральный кроп, скруглённые углы.
- **Фото + часы** — ваше фото с затемнением снизу и большими цифрами поверх.
- **8 шаблонов** — цветовые темы для циферблата и текста.
- Фото сохраняются с постоянным разрешением — не пропадут после перезагрузки.

## Как собрать APK

### Вариант 1. Android Studio (самый простой)

1. Скачайте архив и распакуйте.
2. Откройте папку `WidgetCraft` в Android Studio (**Open** → выбрать папку).
3. Дождитесь синхронизации Gradle (нижняя полоса).
4. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Нажмите **locate** — готовый `app-debug.apk` лежит в
   `app/build/outputs/apk/debug/`. Закиньте на телефон и установите.

### Вариант 2. Через GitHub (APK соберётся сам)

1. Создайте репозиторий на GitHub и загрузите туда содержимое архива.
2. Перейдите во вкладку **Actions** → запустите workflow **Build APK**.
3. Через несколько минут во вкладке **Actions** в деталях запуска появится
   артефакт **app-debug-apk** — скачайте и установите на телефон.

## Как пользоваться

1. На рабочем столе удерживайте пустое место → **Виджеты**.
2. Найдите **Widget Craft** — там три виджета: часы, фото, фото+часы.
3. Перетащите виджет на стол — откроется настройка: выберите стиль,
   при желании нажмите **Выбрать фото**, затем **Добавить виджет**.

## Структура проекта

```
app/src/main/java/com/widgetcraft/app/
├── MainActivity.kt            — галерея шаблонов
├── TemplateAdapter.kt         — сетка стилей с предпросмотром
├── data/
│   ├── WidgetTemplate.kt      — модель шаблона (цвета)
│   ├── TemplateStore.kt       — 8 встроенных стилей
│   └── Prefs.kt               — настройки каждого виджета
├── widgets/
│   ├── ClockRenderer.kt       — рисование циферблата (Canvas → Bitmap)
│   ├── PhotoRenderer.kt       — кроп/скругление фото
│   ├── WidgetUpdater.kt       — обновление виджетов, тикающий приёмник
│   └── Providers.kt           — 3 AppWidgetProvider
└── config/
    └── WidgetConfigActivity.kt — экран настройки при добавлении
```

## Технологии

Kotlin, AppWidgetProvider + RemoteViews, Canvas-рендеринг циферблата,
SharedPreferences, Activity Result API, Material 3. minSdk 26, targetSdk 34.

## Идеи для развития

- Свой цвет через ColorPicker в настройках.
- Погода и дата под часами.
- Несколько фото в одном виджете со сменой по тапу.
- Релизная сборка с подписью (сгенерировать keystore).
